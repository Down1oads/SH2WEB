# Keyboard and mouse

| Action | Binding |
| --- | --- |
| Move | WASD or arrow keys |
| Interact / confirm | E (Z also works) |
| Run | Shift |
| Ready weapon | Hold right mouse button |
| Attack while ready | Left mouse button |
| Flashlight / cancel | F (X also works) |
| Map | Tab |
| Inventory | I |
| Pause | Esc or Enter |
| Sidestep left / right | Q / R |
| Camera / search view | C |
| Quick turn | Space |
| Fullscreen | Alt + Enter, or double-click the game |

The game keeps its original movement mode and actions. The normal page shows
only the game and a green FPS counter in the top-right corner. Audio is enabled;
the first click/key resumes it if the browser blocks automatic playback.
Developer tools appear only with the explicit `debug` URL parameter.
